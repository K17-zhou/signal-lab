## 发布及表单

以下事项需要实际发布地址或参赛者填写，状态待办。

1. 准备 GitHub 或 Gitee 评审仓库，保留细粒度提交历史和三条 Prompt 链。仓库当前仅有本地分支。发布前审查历史中的本机路径、个人信息和任何不宜公开的记录，按规则提供公开或评审访问权限。复现包中的源码快照对应冻结提交。
2. 将完整作品 ZIP 上传主流网盘，保存有效分享地址和所需提取码。把 MP4 发布到可公开播放的视频平台并保留视频页地址。
3. 从未登录视角核对仓库或实际评审授权、网盘下载和视频播放。确认技术 PDF 在完整作品中，作品介绍 PDF 单独上传。若填写发表或获奖信息，按本人已核对的记录更新作品介绍。
4. 参赛者从赛事个人中心进入省赛提交。表单共七个必填项，为 UID、姓名、学校、提交联系人手机号、完整作品文件链接、作品介绍文档和演示视频地址。表单需登录，个人限一次且提交后不可修改。提交后保存回执、实际时间、链接和版本。
