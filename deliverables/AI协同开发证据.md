## 对话范围与核验

- 完整 Prompt 链给出每次迭代的边界、UTC 时间、从 1 起算的 JSONL 行号及源区间 SHA-256。Task 2 和 Task 3 的最终回复取自同一项目的主记录，补足原有私有快照的截止范围。Task 4 收录从真机接入到浏览器验收的三个连续轮次。
- 日志与截图页附「开发对话原文」短摘录，可与完整 Prompt 链对照。完整链中的本机路径和私人记忆引用元数据以标记替换，自动附带的页面上下文、系统与开发者消息、内部推理和工具输出按范围排除。
- 命令保留实际执行的核心子命令，工作目录另列。日志仅保留用于复核的连续行或明确标记的字段，去除 ANSI 颜色、终端排版及机器路径。截图是项目验收时保存的应用画面。对话原始文件、私有聊天标识和机器绝对路径均省略。
- 「开发对话」里的 AI 为 Codex。「运行样本」里的 AI 为应用通过 llama.cpp 调用的本地 Qwen。Task 3 和 Task 4 截图所示的作答来自开发验收中的合成学习会话。真人学习效果为「未测」。
- C 主流程由 Qwen 选择观察重点、证据及可选对照参数，科学正文由程序按已保存指标生成；B 保留普通模型文本，其 81/132 Hz 合成样本中的真实科学错误见[原始样本与说明](ai-evidence/context.md#链-3真实请求失败--收紧科学正文责任)。结构成功、工程验收和合成作答均不等同真人教学效果。

Git 对象、项目内来源路径与图片校验值见[来源索引](ai-evidence/source-manifest.json)；新增前置消息、历史设计／计划、实际模型输入和附件校验值见[上下文来源索引](ai-evidence/context-manifest.json)。
