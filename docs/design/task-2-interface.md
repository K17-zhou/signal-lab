# Task 2 界面与交互基线

使用内置Image Gen生成signal-lab-desktop-concept.png，尺寸1536×1024；它是本轮助手选定的实现参考，并非用户逐项批准的截图。运行页面的所有文字、控件和图表使用原生代码，图中数值不是实验依据。

## 设计系统

- 页面背景#f5f7fb，面板#ffffff，文字#172544，次级文字#65708a，边框#dce1ec。
- 主操作#315efb；原信号#ff7a15，采样点#315efb，周期重建#12b5a5；混叠提示使用浅琥珀底与深橙文字。
- 字体优先Microsoft YaHei/PingFang SC及系统无衬线；正文14–16px，主标题32–36px，面板标题18–20px；所有表单和按钮明确设置字号。
- 顶栏约64px，正文左右32px，参数栏280–300px，主图区域自适应；面板圆角12px，细边框，无营销装饰或图片叠加。
- 组件：AppShell、PresetBar、ParameterPanel、RunSummary、SignalPlots、RunRecord；App只做组合。
- 两幅图纵向排列：时域三种曲线对比、单边幅度谱。小屏参数栏先于结果，案例按钮可换行，图表不造成横向溢出。

## 允许的主要文字与真实操作

- 信号实验工坊；周期正弦实验；导出本次数据。
- 采样、混叠与重建；调节参数，观察同一个信号如何呈现不同的样子。
- 正常采样、混叠、边界退化、DC折叠四个案例，切换后运行真实请求。
- 实验参数；信号频率、采样率、幅度、初相位；运行实验；恢复默认。
- 时域对比；原信号、采样点、周期重建；频谱观察；原始频率、观测主峰、重建误差；实验记录。
- 当前实验限定为1秒周期正弦模型，周期重建不代表能恢复已丢失的信息。

## 交互约束

- 默认混叠案例70Hz/100Hz；默认恢复也回到该案例。所有显示数值来自同一个成功返回的ExperimentRun。
- 参数编辑采用草稿；未运行时显示“参数已修改，运行实验后更新图表”，已有图保持原运行参数归属。
- 后发请求胜出；取消或忽略过时响应，旧结果或旧错误不覆盖新结果。
- 错误、等待、未运行状态明确；计算失败时已有结果标明是上次成功结果，禁止替换成演示数据。
- 导出按钮只导出当前真实运行的JSON；无运行时禁用。

## 为科学正确性所作的明确修正

- 概念图滑块文字存在生成误差：正式范围采用f0=5–200Hz、fs=20–1000Hz、A=0.1–2及相位[-pi,pi]，DC字样按正确拼写。
- 概念图曲线仅为布局示意；正式曲线使用Python实际数组，因此周期数、混叠相位及尖峰形状以真实数据为准，不临摹错误波形。
- 正式实验编号显示真实UUID，不使用概念图虚构的SIG编号。
- 为读图清楚，时域初始显示前0.12秒并加简短说明；计算仍使用完整1秒数据。
- 等待、错误、草稿修改提示为实际异步交互所必需，延续同一视觉系统。
