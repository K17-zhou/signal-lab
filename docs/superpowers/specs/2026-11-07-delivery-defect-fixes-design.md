# 初版交付缺陷修复设计

用户在核对 B站视频要求后，要求先把已列出的缺陷全部处理。目标是保留真实开发历史，提供有教学目的的 AI 对照、可直接运行的 Windows 演示包，以及连续实操视频和实际可访问的发布链接。

## 修复范围与方案

1. 对照建议保留模型原始选择，服务端用数值引擎核对其教学目的。恢复原频率的对照固定信号与振幅相位，采样率严格超过两倍频率；边界相位对照单独验证并说明适用范围。未通过的建议置空，原预测与证据保留。B 原始文本基线继续保存原样。
2. 快速复现采用自带 Python、锁定依赖、前端构建、固定权重与 llama.cpp 的便携包，提供 Windows 双击入口。下载源与开发安装路径继续可查。只优化网络下载无法保证首次复现时长，替换已定模型也不能解决环境安装问题，因此选择便携运行环境。
3. 视频采用真实浏览器连续录制，展示实际计算、本地模型、证据定位、确认对照、迁移及恢复。AI 协同段展示本次真实修复任务、约束、实际差异及失败/通过验证，重放的历史内容明确标注，不能伪装为原始录屏或即时模型生成。
4. 新版视频发布 B站，完整包发布用户选择的百度网盘；成功后验证公开播放/下载并记录 URL。账号登录由用户完成，正式赛事表单仍暂缓提交。

## 验收边界

所有新文件放在用户指定项目目录。现有 `测试` 环境保留，新包使用其下新子目录验证。便携运行不依赖系统 Python、Node.js、npm 或 PowerShell 7，也不修改全局配置。网络下载、解压后启动与功能完成分别计时，不承诺任意网络或任意机器的总耗时。

原 v1.1、原留出用例与题目、真实失败记录均保留。真人测试与异机测试按既有范围仍未实施。新结果单独标版本，不把旧版数值或合成数据写成教学效果。
