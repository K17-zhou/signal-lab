## 技术验收

两条合成会话在隔离 SQLite 库运行，实际调用本机 Qwen3.5-4B Q4_K_M 和 llama.cpp b11814。两次请求均返回 HTTP 200，耗时为不同题目、不同调用顺序下的单次实测。

| 条件 | 题目 | 观测结果 | 指导请求 |
| --- | --- | --- | ---: |
| B-X | 32 Hz 信号以 156 Hz 采样 | 主峰 32 Hz，普通文本说明，迁移题 44 Hz 判对 | 25.453 秒 |
| C-Y | 81 Hz 信号以 132 Hz 采样 | 主峰 51 Hz，引用 3 项实测证据，确认 200 Hz 对照后主峰 81 Hz，迁移题 55 Hz 判对 | 5.481 秒 |

C 组浏览器点击引用后，摘要获得焦点并显示 51 Hz 证据。确认对照后，刷新恢复了 22 Hz 原预测、81 Hz 图表和迁移判分。真实模型验收的桌面视口为 1265 × 720。 [B 组合成验收](../evidence/screenshots/task6-synthetic-b-real-model.jpg) [C 组合成验收](../evidence/screenshots/task6-synthetic-c-real-model.jpg)

冻结用例共 30 条，其中 20 条数值与边界、10 条指导与交互。7 条数值和 3 条交互指定为 Task 7 留出用例。独立 DFT 验算了两套题的 8 个数值答案，边界相位公式验算了 4 个单选答案。 [用例清单](case_manifest.csv) [冻结校验表](frozen_inputs.sha256)

最终后端 122 项、前端 16 项测试通过，生产构建通过。Playwright 用本机 Chrome 跑过参数切换、B 组刷新和导出、C 组证据与对照、超时和后续作答四条流程。Windows 环境采用单独启动合成服务的方式，测试命令正常退出。评估脚本读取该服务的四份合成会话导出后，仍返回正式真人样本 0 和「未测」。

回归测试复现了试用数据库更换分配表、第二实例抢先恢复调用、指导进行中导出和脱离原实验的迁移记录。修正后数据库保留原分配，导出等待指导进入终态，统计核对同会话的预测、原始运行、指导和迁移题。
